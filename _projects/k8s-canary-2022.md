Responsible for developing Terraform recipes to deploy Kubernetes clusters on AWS EKS, meeting all environment requirements and ensuring compliance with regulatory standards. Implemented Karpenter for enhanced node management, migrated node operating system to Bottlerocket, and deployed ArgoCD for GitOps processes. The rollout was executed using a canary strategy, migrating traffic between clusters gradually.
Key Outcomes:
- Significantly increased Kubernetes cluster maturity
- Improved security
- Enhanced operational agility and observability
- Reduced costs
